SQL-базы данных

Реляционные СУБД — классика веб-разработки, основанная на строгой схеме и языке SQL.

Основные представители

  • PostgreSQL — объектно-реляционная СУБД с открытым кодом.
  • SQLite — встраиваемая база данных.
  • MySQL / MariaDB — популярна в веб-проектах.
  • Oracle Database — корпоративный стандарт.

Пример SQL-запроса

SELECT u.name, COUNT(o.id) AS orders_count
FROM users u
LEFT JOIN orders o ON o.user_id = u.id
GROUP BY u.name
ORDER BY orders_count DESC;

Преимущества

  1. ACID-транзакции.
  2. Строгая типизация и целостность данных.
  3. Мощный язык запросов.
