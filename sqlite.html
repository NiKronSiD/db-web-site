SQLite

Встраиваемая реляционная база данных, не требующая отдельного сервера.

Где используется

  • Мобильные приложения (Android, iOS).
  • Браузеры (Chrome, Firefox).
  • Прототипы и небольшие проекты.
  • Встроенные системы и IoT.

Пример работы

sqlite3 test.db
CREATE TABLE users (id INTEGER PRIMARY KEY, name TEXT);
INSERT INTO users (name) VALUES ('Alice');
SELECT * FROM users;

Преимущества

  1. Нулевая конфигурация.
  2. Один файл — вся база.
  3. Кроссплатформенность.
