MongoDB

Документоориентированная NoSQL-база данных с гибкой схемой.

Особенности

  • Хранение данных в BSON-документах.
  • Горизонтальное шардирование.
  • Агрегационный пайплайн.
  • Replica Set для отказоустойчивости.

Пример запросов

db.users.insertOne({ name: "Alice", age: 30 });
db.users.find({ age: { $gt: 25 } });
db.users.aggregate([
  { $group: { _id: "$age", count: { $sum: 1 } } }
]);

Когда выбирать MongoDB

  1. Быстрые прототипы и MVP.
  2. Каталоги товаров с разной структурой.
  3. Real-time аналитика и логи.
