PostgreSQL

Объектно-реляционная СУБД с открытым исходным кодом.

Особенности

  • Поддержка JSON/JSONB.
  • Расширения (PostGIS, TimescaleDB).
  • MVCC и высокая надёжность.
  • Полнотекстовый поиск из коробки.

Пример подключения (Node.js)

const { Client } = require('pg');
const client = new Client({ connectionString: process.env.DATABASE_URL });
await client.connect();

Где применяется

  1. Высоконагруженные веб-приложения.
  2. Геоинформационные системы.
  3. Аналитические платформы.
